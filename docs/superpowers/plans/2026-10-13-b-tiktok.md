# Parça B — TikTok takip edilenlere DM · Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aynı kod tabanından ayrı bir TikTok bot süreci (`run.py --platform tiktok`) TikTok'ta takip ettiğimiz ama hiç yazışmadığımız hesaplara kendi kotasıyla DM açılışı atsın; panel platform seçiciyle iki botu ayrı yönetsin. Instagram davranışı değişmez.

**Architecture:** Ortak Playwright kodu `tarayici.py`'deki `TarayiciIstemci` temel sınıfına taşınır (`InstagramClient` ve yeni `TikTokClient` ondan türer; takip listesi önbelleği ve `acilis_turu` döngüsü de temelde). `bot_state` anahtarları `platformlar.anahtar(platform, ad)` ile ayrılır: Instagram öneksiz, diğerleri `tiktok:ad`. Repository'nin durum fonksiyonları, `canli_ayarlar`, `scheduler`, `run`, `surec` ve panel `platform` parametresi alır (varsayılan `instagram`). TikTok süreci yalnızca mevcut `scheduler.direkt_dm_turu_yap`'ı çalıştırır.

**Tech Stack:** Python 3.12, SQLite (WAL), Playwright (sync), Streamlit 1.65, pytest.

**Spec:** `docs/superpowers/specs/2026-10-13-cok-platformlu-dm-design.md` (bölüm 2.5, 3, 3.1, 4.2, 4.4, 5, 6, 8-B)

**Bu parçada bilinçli olarak YOK:** Facebook istemcisi (parça C; `istemci_olustur("facebook")` açık bir `ValueError` verir, panel seçicisinde Facebook yok), TikTok gelen kutusu / yanıt (`RESPOND` yalnızca IG), TikTok'ta hikaye turu ve hashtag keşfi, IG hikaye turunun `bot_state` anahtarlarına dokunulması (IG zaten öneksiz).

## Global Constraints

- Python: her komut `.venv/bin/python3.12` ile; testler `.venv/bin/python3.12 -m pytest tests/ -q` (main'de 122 test yeşil).
- Instagram `bot_state` anahtarları **öneksiz** kalır (`master_paused`, `ayar.yeniden_iletisim_gun`, `bot_pid`, …); diğer platformlar `f"{platform}:{ad}"`.

def _platforma_uyarla(ayarlar: Ayarlar, platform: str) -> None:
    """IG varsayılanlarını başka platform için değiştirir (ayrı profil, kota)."""

    ayarlar.pacing.dm_acilis_gunluk = _int(f"{on}_DM_ACILIS_GUNLUK", gunluk)
